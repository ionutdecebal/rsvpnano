# RSVP Nano v0.2.0 — New UI preview

An optional new interface for **Waveshare ESP32-S3 Touch LCD 3.49 Rev1**.
Classic stays available and remains the default stable software. Other boards
should continue using Classic. This release is RSVP Nano; Pocket Lines is a
separate development track.

## Included

- A quieter reading screen, consolidated settings, larger touch targets and full-area sliders.
- Centred contextual chunks alongside single-word reading, with adjustable pacing.
- Page browsing, book search and chapter navigation. Page view is for browsing;
  playback uses Word or Chunk mode. Returning to the reader restores its selected font size.
- Focus sessions alongside reading or as standalone timers, presets, full-screen
  breaks and manual resume after a break.
- First-use onboarding covering physical buttons, speed/pacing, SD checks, book
  uploads and dictionary setup. Replay it from Settings → Help.
- Offline English definitions, a verified Wi-Fi dictionary installer, and optional
  direct online lookup through Wiktionary. More dictionary languages are planned.
- Quick controls on the middle button; per-book language/font settings in Library.
  Reading guides are hidden in Chunk mode. Sentence-end pause and touch refinements
  from the tested candidates are included.

Voice notes, microphone recording, transcription, Bluetooth phone sync and the
experimental new phone app are not included. Their existing SD data is left alone.

## Install or update

Use the [web companion](https://ionutdecebal.github.io/rsvpnano/) and select LCD 3.49
Rev1 → New UI (preview). For manual installation use the merged
`rsvp-nano-esp32-s3-touch-lcd-3.49.bin`. Leave **Erase first off** and back up the SD.
The `-ota.bin` is application-only firmware for OTA, not the browser flash file.

The complete ZIP includes firmware, dictionary files, the review board, demo text,
checksums and instructions. The dictionary is not embedded in the firmware image.

In Firmware updates, **Check current software** follows New UI. **Return to Classic**
selects the compatible Classic maintenance release for confirmation. Classic v0.1.3
adds **Try New UI** on Rev1. Switching is an explicit firmware install and restart.
Both use the same SD library; Classic may replace New UI-only preferences when saving.

## English dictionary

From a book, press the middle button → Dictionary → ? → Install / manage dictionary,
then Install dictionary. It downloads about 48 MiB to SD over Wi-Fi and verifies the
stream and saved file. Replacing an existing pack asks first. The middle button
cancels; retry starts again.

For manual installation, extract the attached dictionary ZIP and copy its
`dictionaries` folder to the SD root. The same pack is independently hosted in the
[English dictionary release](https://github.com/ionutdecebal/rsvpnano/releases/tag/dictionary-en-2025.1).
Keep its attribution and licence files. Offline reading and definitions need no
account, phone or server. Look online sends only the lookup word directly to Wiktionary.

## Validation and limits

The founder tested the preceding candidates on LCD 3.49 Rev1 and confirmed reading,
page view, Focus, dictionary downloading and a browser-flashed Classic/New UI round
trip. These final builds keep the same firmware implementation, with final version
identities and release documentation.

Local validation includes native UI/settings tests, production-renderer captures,
dictionary corruption/lookup checks, simulated download/SD interruption cases,
settings compatibility and firmware-image integrity checks. A browser-flashed round
trip does not establish real Wi-Fi OTA behavior. Full live OTA round-trip results and
largest-font 1000-WPM performance are not claimed by this release.

Please report the interface, firmware version, board revision and reproduction steps
when sharing feedback. Screenshots in the review board use synthetic fixture content.
