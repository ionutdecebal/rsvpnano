# v0.0.10

## Watch-sized device UI

- Dedicated layouts for AMOLED 2.41, 2.16, 2.06, and 1.8 v1/v2, and LCD 1.47.
- Rounded controls and a colored, expanding navigation dock for Read, Settings,
  Device, and Focus. Settings retain their existing categories.
- Larger text, paged settings, and directly accessible USB and Companion sync.
- Chapter and user-created timer carousels support horizontal swipes and side
  taps; a separate center tap activates the selected item.
- Circular progress displays and a WPM dial with relative horizontal dragging
  and explicit minus/plus buttons.
- Reader chrome and page-reading typography adapt to the smaller displays,
  including vertical CJK reading.
- Each board compiles only its selected presentation. Reading, settings, timer,
  and storage workflows continue to use the shared implementation and UI library.
- The LCD 3.49 keeps its existing presentation.

## Reading and pacing

- Treat em dashes as word boundaries and apply the existing dash pause, including
  decoded HTML entities. Hyphenated compounds remain intact.
- Rebuild older book indexes so existing books use the corrected tokenization.

## Website

- Appearance catalogs load after device settings arrive, refresh when the catalog
  source changes, and reload when switching devices. This fixes catalogs remaining
  empty after an initial connection or page refresh.
- Includes the previously merged web-installer dependency fix and automatic Pages
  deployment for web-related changes on main.

## Testing notes

The new UI has host interaction/layout tests across all supported watch
resolutions and firmware build checks. Physical display appearance, touch feel,
orientation, and device-specific behavior still need community testing. Please
include the board model, display orientation, and steps to reproduce in reports.

Arrow-hiding settings and unrelated companion settings changes are not included.
