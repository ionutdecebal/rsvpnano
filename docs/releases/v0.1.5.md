# RSVP Nano v0.1.5 — Classic and New UI choice on LCD 3.49 Rev2

This small Classic maintenance update adds **Try New UI** to LCD 3.49 Rev2.
Classic remains the stable/default interface, and normal updates keep your
chosen interface. Rev1 keeps its existing choice.

## Update and choose

1. On an older Classic installation, check for the normal official firmware
   update and install v0.1.5. The legacy LCD OTA filenames remain available.
2. On LCD 3.49 Rev1 or Rev2, open **Firmware updates → Try New UI**.
3. Review the version, then confirm installation. In New UI, use **Return to
   Classic** to switch back.

New UI v0.2.0 remains available for Rev1. Rev2 uses the separately tagged
v0.2.0-rev2.1 port, with the same UI, onboarding and dictionary. Each revision
receives its own image; the firmware and delivery catalog reject a mismatched
board or asset. Other boards continue using Classic.

Back up your SD settings and progress before switching. Both interfaces use the
same books, but interface-specific preferences may change when saved. No SD
format or flash partition migration is required. In the browser installer,
choose the exact board revision and keep **Erase first off**.

## Downloads and compatibility

For manual browser flashing, extract the matching full image from
`rsvp-nano-browser-installers.zip`. Individual `-ota.bin` files are application-only
images. The legacy `rsvp-nano-ota.bin` and `rsvp-nano-rev2-ota.bin` aliases remain
exact copies of their board-specific OTA images. Release metadata stays within
the old updater's 32 KiB discovery limit.

The update descriptor includes both LCD revisions. Runtime changes from v0.1.4
are limited to the Rev2 interface choice and catalog support; display, touch,
reading, storage and partition layout are unchanged.

## Validation

Both board/channel combinations and wrong-board rejection have native tests.
All nine firmware targets are built, and release assets, embedded versions,
merged/OTA pairs, partitions and legacy discovery are verified before publication.
The owner tested the New UI Rev2 port on hardware and reported that it performs
well. Host delivery checks do not establish a physical Rev2 OTA round trip or a
1000 WPM benchmark; those remain device checks.
