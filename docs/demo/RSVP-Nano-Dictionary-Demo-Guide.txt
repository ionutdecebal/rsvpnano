RSVP NANO - DICTIONARY DEMO CHEAT SHEET

UPLOAD THIS FILE TO THE READER:
RSVP-Nano-Dictionary-Demo.txt

Use the web companion's Library upload as you would for any text book.
This cheat sheet is for you; it does not need to be uploaded.

BEFORE THE DEMO

Install the English dictionary pack on the SD card. For Part Two, save a
working Wi-Fi connection under Connections. Offline lookup needs no network.
Use a comfortable reading speed; Word mode makes individual words easy to select.

HOW TO SHOW A DEFINITION

Pause near a target word, press the middle button, and open Dictionary.
Use the Word arrows to select a nearby word if you paused just past it,
or use Search to type the exact word below.

PART ONE - OFFLINE LOOKUP

These are present in the released English pack, in story order:

1. serendipity
2. luminous
3. mellifluous
4. ephemeral

A definition should appear immediately, with Open English Wordnet as its source.
You can demonstrate this without an internet connection.

PART TWO - ONLINE LOOKUP

These are absent from that pack, in story order:

1. petrichor
2. sonder
3. solarpunk

First show the "No offline entry" message, then tap "Look online".
With working Wi-Fi, the lookup should return a Wiktionary English definition.
The online request is deliberate; it is not automatic when an offline entry is missing.
An online lookup does not permanently add the word to the offline dictionary.

QUICK VERSION

Search for serendipity to show an offline result.
Search for petrichor to show a missing offline entry, then tap Look online.
