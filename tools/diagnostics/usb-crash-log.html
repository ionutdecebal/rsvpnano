RSVP NANO / DIAGNOSTICS

Capture a firmware problem.

This page reads USB logs from your current firmware. It does not install firmware, send commands, or upload anything.

  1. Open this file in desktop Chrome or Edge. Connect the Nano with a USB data cable and close other serial monitors.
  2. Click Connect USB and select the Nano. Leave this page open.
  3. On the Nano, repeat the action that causes the problem.
  4. Wait for the Nano to restart. If USB disconnects, this page tries to reconnect; you can also click Reconnect USB. Do not manually reset it again.
  5. Click Save log and send the downloaded text file back.
